# 文档动作与输出路径统一规范（四件套）

> 2026-10-07 建立。本文只做规范索引与口径声明，可执行逻辑一律以指向的源文件为准。
> 核对命令示例：`Select-String -Path Pages\**\*.xaml -Pattern '预览|打印|保存|全部保存'`（改动作前先跑一遍）。

## 1 四件套定义（预览 / 打印 / 保存 / 全部保存）

| 动作 | 语义（铁律） |
|---|---|
| 预览 | 生成**临时** PDF 供内嵌预览或弹窗；临时文件走 `OutputPathHelper.GetTempDirectory()`（启动时清理），**不入**输出文件列表 |
| 打印 | **生成 + 落盘输出根 + 调打印机**（`PrintExecuteService` 的 `printToPrinter: true`；直打域 `printToPrinter` 参数贯穿） |
| 保存 | **仅生成 + 落盘输出根**，不打印（`printToPrinter: false` 或独立保存命令） |
| 全部保存 | 同"保存"，范围=全部条目，**不依赖勾选**（单条目场景可省略，如核查报告） |

辅助动作：**打开输出目录**（`ViewModelBase.OpenOutputFolderCommand`，先确保目录存在再打开）。

- 文案常量单一来源：`Constants\DocumentActionText.cs`；MAUI 无 `x:Static`，XAML 经 `ViewModels\Base\ViewModelBase` 的实例属性中转（`PreviewActionText` / `PrintActionText` / `SaveActionText` / `SaveAllActionText` 及 `*SelectedActionText`、`OpenOutputFolderActionText`）。**禁止在 XAML 自造动作按钮文案**。
- 行级按钮用"选中行"三件套（预览/打印/保存），工具栏用整表四件套；图标用 `StringFormat='&#xE8xx; {0}'` 前缀。

## 2 输出路径口径

- **唯一输出根**（优先级从高到低）：
  1. **用户级覆盖**：`{AppData}\document_output.user.json`（主页顶栏设置按钮 → `Pages\Config\SettingsPage` 写入；升级/重装不丢）；
  2. `config\document_output.yaml` → `output.base_directory`（支持 `{Documents}`=用户文档、`{AppData}` 占位；Android 上 `{Documents}` 落应用私有存储）；
  3. 回退历史相对目录`输出`。
  读取链：`IConfigService.GetDocumentOutputOptions()`（`Services\Core\ConfigService.cs`，含 `Set/ResetDocumentOutputBaseDirectory`）→ `Models\Options\DocumentOutputOptions` → `Helpers\OutputPathHelper.Configure/OutputRoot`（运行期改根即时生效）。
- 目录规划：`{输出根}\{功能分类}\…`（如 `核查报告\`、`月报表\{期间}\`、`高龄月报\{期间}\`）；`OutputPathHelper.GetTempDirectory()` 只用于预览与打印中转。
- **禁止**：本动作集使用 `PickExportFolderAsync` 弹目录选择（临时/一次性外部目录需求除外）；硬编码相对 `输出` 路径（唯一有意回退在 `ConfigService` 解析失败分支）。改输出根的唯一入口是系统设置页（`SettingsViewModel.ChangeOutputRootCommand`，一次性选择、全局生效；该处的目录选择属配置场景，是本禁止条款的例外）。
- **历史根迁移**：`Services\Core\OutputRootMigrationService`（`IOutputRootMigrationService`）——旧根由 `{AppData}\output_root_state.json` 判定（无状态文件=旧默认 `{AppData}/CosmosApp/ArchiveOutput`），启动后台一次性复制到当前根（跳过 temp 与已存在文件）+ 改写留痕表路径列 + 清理旧根临时目录；状态仅在成功后更新（失败下次启动重试）；新旧根互为包含时拒绝（`OutputPathHelper.ArePathsNested`，防自复制死循环）。用户改根后由设置页即时触发同一迁移（`MigrateToAsync`）。
- 核查报告落盘命名权威：`核查报告_{yyyyMMddHHmmssfff}.pdf`（`ArchiveOutputViewModel.PrintVerificationReportAsync` 与 `MonthlyAssetAuditViewModel.CreateReportFileAsync` 同规则）。

## 4 禁止事项（新增功能时自查）

1. 保存/打印不落输出根、直接进 temp 或弹目录选择器。
2. XAML 自造"导出/一键/生成预览"等动作文案（应接 `DocumentActionText`）。
3. 预览动作把临时文件写入输出文件列表（会把即将被清理的路径当正式产物）。
4. 只实现打印不实现保存（或反之）——同屏动作必须四件套齐全（单条目场景允许省"全部保存"）。
5. 打印失败吞异常当成功；保存失败必须显式提示（Result 模式，见 AGENTS §7）。
