# 临时救助 C 线时间轴口径（重构）

> 2026-10-18。以**验收日为锚**重排 C 线（临时救助验收线），公示/入户调查全部按日历日倒推。
> 权威实现：`Services\Utilities\BusinessTimelineService.cs`（`CalculateCLine`）；本文记录口径与决策，不复述代码。

## 1. 节点口径

| 节点 | 规则 |
|---|---|
| 验收日 A | 当月 **13 号**；若为非工作日 → **顺延至其后最近工作日**（保证必为工作日） |
| 公示止 | A − 1（日历日，**不排工作日**） |
| 公示起 | A − 3（日历日，**不排工作日**） |
| 入户调查窗口 | **[A − 5, 公示起]**（起日 = A−5；截止 = 公示起日） |
| 申请日期上界 | A − 5（= 入户调查窗口起日） |

- `TimelineResult` 映射（C 线）：`PublicityStart/End`、`InvestigationStartDate`=A−5、`InvestigationDeadline`=公示起、`AuditDate`=A、`Cycle*`=[A−5, A]。
- 当 13 号为工作日的月份，本口径与旧实现（公示固定 10~12、验收=公示止次一工作日）**完全等价**；差异只出现在 13 号撞周末/节假日的月份。

## 2. 打印 / 文书取值

- **验收日** = A；
- **入户调查时间** = `clamp(今日的最近工作日, [A−5, 公示起])`：工作日取今日、周末/节假日回退至最近工作日、早于窗口起日（窗口未开启）取起日、晚于窗口截止（补打历史档案）兜底为截止日——保留"不为未来日"原则；
- 公示起止 = 库中值。

## 3. 表单录入自动修正（不报错）

- 申请日期统一修正为「不晚于今日」，再按其所在月取 C 线窗口；若仍晚于该月**入户调查窗口起日（A−5）** → **自动钳到 A−5**；
- **取消旧"滚月"归属**（旧：申请日超过窗口即整档顺延下月）与旧"调查窗口下界上推"；
- 删除保存时"申请日期越界/晚于今天"的报错——录入即自动修正，不再阻断保存；
- 公示起止随修正后月份窗口自动生成。非草稿（编辑/查看已存档案）保留库中原值，不重算、不修正。
