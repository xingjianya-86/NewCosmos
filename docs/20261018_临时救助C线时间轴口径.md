# 临时救助 C 线时间轴口径（重构）

> 2026-10-18。以**验收日为锚**重排 C 线（临时救助验收线），公示/入户调查全部按日历日倒推。
> 权威实现：`Services\Utilities\BusinessTimelineService.cs`（`CalculateCLine`）；本文记录口径与决策，不复述代码。
>
> ⚠️ **2026-10-20 修订**：§3 的“不滚月 + 申请日期钳到 A−5”已废止（它让 10-14 之后录入的申请被回填成 10-08、归属永远停在本月）。
> 现行归属 = **申请日 ≤ 当月验收日 A 归本月，超过 A 顺延下月，申请日期不改写**；
> 决策与影响见 `docs\20261020_临时救助C线申请日期归属滚动.md`。§1 的“申请日期上界”与 §3、§6 已按新口径同步。

## 1. 节点口径

| 节点 | 规则 |
|---|---|
| 验收日 A | 当月 **13 号**；若为非工作日 → **顺延至其后最近工作日**（保证必为工作日） |
| 公示止 | A − 1（日历日，**不排工作日**） |
| 公示起 | A − 3（日历日，**不排工作日**） |
| 入户调查窗口 | **[A − 5, 公示起]**（起日 = A−5；截止 = 公示起日） |
| 申请日期归属上界 | **A（验收日）**：申请日 ≤ A 归当月批次，超过 A 顺延下月（2026-10-20 修订；A−5 只是**调查窗口起日**，不再是申请上界） |

- `TimelineResult` 映射（C 线）：`PublicityStart/End`、`InvestigationStartDate`=A−5、`InvestigationDeadline`=公示起、`AuditDate`=A、`Cycle*`=[A−5, A]。
- 当 13 号为工作日的月份，本口径与旧实现（公示固定 10~12、验收=公示止次一工作日）**完全等价**；差异只出现在 13 号撞周末/节假日的月份。

## 2. 打印 / 文书取值

- **验收日** = A；
- **入户调查时间** = `clamp(今日的最近工作日, [A−5, 公示起])`：工作日取今日、周末/节假日回退至最近工作日、早于窗口起日（窗口未开启）取起日、晚于窗口截止（补打历史档案）兜底为截止日——保留"不为未来日"原则；
- 公示起止 = 库中值。

## 3. 表单录入归属与自动修正（不报错）

> 本节 **2026-10-20 改写**：原“不滚月 + 钳到 A−5”口径已废止（见页首 2026-10-20 修订注记）。

- 申请日期先修正为「**不晚于今日**」（只有未来日期被拉回今天，**过去日期一律原样保留**）；
- 归属：**申请日 ≤ 当月验收日 A → 当月批次；超过 A → 顺延下一个月**（跨年自动接续，最多防御性顺延 24 个月）；
- 公示起止 / 验收日 / 入户调查窗口取**归属月**窗口；**申请日期本身不再被回填或钳制**；
- 表单在申请日期下方显式显示“本次归属：{年}年{月}批次（公示 …~…，验收 …）”，归属结果对录入人可见；
- 删除保存时“申请日期越界/晚于今天”的报错——归属由滚月决定，不再阻断保存；
- 公示起止随归属月窗口自动生成。非草稿（编辑/查看已存档案）保留库中原值，不重算、不修正、不显示归属提示。

**边界说明**：申请日落在 A−5 ~ A（本月即 09~13 号）时仍归本月，但本月公示期早于或等于申请日，
打印出的公示起止会早于申请日期——这是 A 口径的固有边界；如需消除，把滚月比较由 `AuditDate` 改成 `InvestigationStartDate`（A−5）即可。
