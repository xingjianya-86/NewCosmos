## 一、缺口描述

货币财产核对现**只有 30 个月档、无申请类别区分**：

| 位置 | 现状 |
|---|---|
| `Constants\BankFlowConstants.cs:11` | `BalanceLimitMonths = 30`（单一常量） |
| `ApplicationFormViewModel.BankFlow.cs:181`（表单红字提示） | `月低保标准 × 30 × 家庭人数`，不分申请类别；文案 `BalanceExceedFormat` 写死「30 个月」 |
| `BankFlowImportService.cs:601`（批量导入初筛） | `min(城乡标准) × 30`，无类别信息 |

**法定口径**（牡民规〔2024〕2号 = 黑民规〔2024〕7号，同款）：

| 类别 | 条款 | 货币财产条件 |
|---|---|---|
| 最低生活保障家庭 | 第二十条(二) | 人均 ≤ **30 个月**城乡低保标准 |
| 最低生活保障边缘家庭 | 第二十五条(二) | 人均 ≤ **36 个月**城乡低保标准 |
| 刚性支出困难家庭 | 第二十六条(二) | **财产认定条件参照边缘家庭** → 36 个月 |
| 单人保（参照单人户**纳入低保**） | 第二十五条末段 | 已入低保 → 30 个月 |
| 特困供养 | — | 无法定货币财产月数条件 |

→ 边缘/刚性支出申请按 30 个月提示会**误报超阈值**（把合法的 30~36 个月区间标红）。

## 二、改动方案

### 改动 1 · `BankFlowConstants`（档位单点）

```csharp
/// 低保档（第二十条(二)：人均 ≤ 30 个月）
public const int BalanceLimitMonths = 30;            // 保留现名，语义 = 低保档（既有调用默认档）
/// 边缘档（第二十五条(二)：人均 ≤ 36 个月；刚性支出第二十六条(二)参照边缘同档）
public const int BalanceLimitMonthsEdge = 36;

/// 按分类码取货币财产月数（单点映射；未知/未判定 → 30 从严）
public static int MonthsFor(string? classificationCode) { ... }

/// 提示文案参数化月数：把 BalanceExceedFormat 中写死的「30」改为占位（保留旧串兼容或直接改格式串+调用方）
public const string BalanceExceedFormat = "家庭货币财产合计 {0} 元，超过 {3} 个月低保标准（{1} 人 × {3} × 月标准 = {2} 元），仅提示，请人工核定";
```

`MonthsFor` 映射（分类码常量引用 `ClassificationConstants`，不写字面量）：

| 分类码 | 档位 |
|---|---|
| `RuralSubsistence` / `UrbanSubsistence`（低保） | 30 |
| `RuralLowIncomeSingle` / `UrbanLowIncomeSingle`（单人保→已入低保） | 30 |
| `RuralLowIncome` / `UrbanLowIncome`（边缘） | **36** |
| `RuralRigidExpenditure` / `UrbanRigidExpenditure`（刚性支出→参照边缘） | **36** |
| `RuralDestituteScattered/Centralized`、`UrbanDestitute…`（特困，无法定条件） | 30（从严提示） |
| 其余（超标/拒保/未判定/null） | 30（从严，不误导漏报） |
