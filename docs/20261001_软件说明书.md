## 1 软件概述

### 1.1 定位

本系统是面向乡镇/街道民政业务的一体化应用，覆盖**低收入人口认定与动态管理、高龄津贴发放、家庭经济状况核对、救助档案制作与查询、后补追缴、统计月报**等核心业务，实现"申请—审核—公示—建档—复核—变更—停发—报表"全流程数字化。

### 1.2 核心能力

- **认定审核确认**：五步申请表单、收入核算（年值权威口径）、三层分类判定（低保 / 低保边缘家庭 / 特困人员 / 刚性支出困难家庭 / 单人保）、渐退期管理、特殊审批。
- **动态管理**：经济状况复核、家庭信息修正、成员增减、户主变更、户主死亡链（停旧建新、接续链追溯）、保障金调整。
- **高龄津贴**：申请登记、类别复核、停发办理、月度报表。
- **家庭经济状况核对**：快速核对、报告上传与月度审核、核对月报表。
- **档案与文书**：Word/Excel/PDF 模板引擎（兼容 Office/WPS）、PDF 预览、档案制作、月度公示、统一补打。
- **统计报表**：月报（B 线周期统计）、分类施保增减、停保/新增汇总、低收入证明等打印。
- **系统管理**：RBAC 角色权限 + 数据权限、组织与经办机构、数据字典、地区库、标准配置、备份恢复、数据导入导出、在线更新。

### 1.3 平台形态

| 形态 | 说明 |
|---|---|
| Windows 桌面端 | 主形态，WinUI 3（.NET 10 MAUI，未打包），自包含发布，双击安装即用 |
| Android 移动端 | 同工程多目标编译（`net10.0-android36.0`），提供手机界面的申请、复核、变更、核对、值班等操作 |

## 3 安装部署与首次启动

### 3.1 安装步骤

1. 运行 Inno Setup 安装包（`NewCosmos-Setup-x.y.z.exe`），按向导完成安装（默认安装至 Program Files，可自选目录）。
2. 首次启动进入**配置向导**：填写数据库连接（Host / Port / DatabaseName / Username / Password），写入安装目录下 `config\database.ini`。
3. 应用**首次启动自动执行**：建表、补索引、补外键（Schema 幂等初始化，约 42 个 Schema 定义）、种子数据合并、数据库清单校验（启动页可见"Schema 状态检查"结果）。
4. 首次保存数据库密码后自动加密为 `enc:` 前缀密文（Windows DPAPI **机器级**加密）。

### 3.2 部署注意

- `config\database.ini` **不随代码仓库分发**；明文密码仅存在于部署机，首次启动即转密文。
- **密文不可跨机复制**——整机迁移/重装后需重新在配置向导中填写一次密码。
- 数据库账号需具备建表/建索引权限（初始化与升级需要）；日常运行账号权限按最小化原则配置。
- `Scripts\` 目录存放彩票模块 Python 脚本等运行资源（经 csproj 复制进应用输出，随包分发），发版脚本在 `deploy\`；涉及数据库口令一律读环境变量 `NEWCOSMOS_DB_PASSWORD`，禁止明文写入文件。

## 4 功能说明

主界面为"左侧导航 + 首页工作台"结构，导航分组：**工作台 / 救助业务 / 核对·档案 / 系统管理**。

### 4.1 首页工作台

- **数据概览卡片**：本月总新增（户）、本月总退出（户）、新申请经济核对（件）、本月新增高龄老人（人），均按当前统计周期实时汇总。
- **提醒横幅**：Schema 状态警告、渐退期即将到期名单、高龄津贴提醒、大学生就学提醒。
- **业务模块卡片**：一键进入各业务模块。

### 4.2 低收入人口救助帮扶（核心模块）

| 功能 | 说明 |
|---|---|
| 救助申请表单 | 五步向导：基本信息 → 家庭成员 → 收入财产 → 分类判定 → 提交；支持草稿保存 |
| 收入核算 | 年值为权威口径：月项×12 + 赡养/土地/补贴年值 − 刚性支出×12，先汇总后一次舍入到分；月均值仅作分解显示 |
| 分类判定 | 三层分类（低保 / 边缘 / 特困 / 刚性支出 / 单人保），人均月收入精确口径判定，公式单点实现 |
| 渐退期管理 | 渐退登记、渐退到期清单、渐退确认、减发核定与文书输出 |
| 审批工作流 | 四标签页：草稿 / 已建档 / 已完结 / 资产核查联动；卡片操作（编辑、删除、档案制作、**查看档案（只读）**） |
| 动态管理 | 经济状况复核、家庭信息修正、成员变更、户主变更、户主死亡（停旧建新 + 接续链） |
| 特殊审批 | 特困等特殊情形审批表单（创建/审核/打印分权） |
| 能力评估 / 大学生管理 / 近亲属单人保 | 专项业务台账与入口 |
| 临时救助 | 临时救助申请登记与台账列表 |

### 4.3 高龄津贴发放

申请登记 → 待审列表 → 审核 → 停发办理 → 类别复核 → 高龄月报表；含自然月受理登记统计与到期提醒。

### 4.4 家庭经济状况核对

- **快速核对**：新申请经济核对发起。
- **月度核对**：报告上传、月度审核。
- **核对月报表**：按周期统计核对件数与结果。
- 首页"新申请经济核对"卡片显示"已申未出报告"件数。

### 4.5 救助档案管理

- **档案制作**：按模板批量生成文书（告知书、审批表、增减员表等），输出 Word/Excel/PDF。
- **档案查询**：现存与历史档案检索，查看档案详情（只读），支持变更记录追溯。
- **月度公示**：公示名单生成与打印。
- **文书模板管理**：模板上传、FieldKey 映射维护。
- **统一补打**：已生成文书的补打入口。

### 4.6 后补追缴

已停保对象的后补追缴：搜索停止人员 → 填写追缴信息 → 手工录入 → 追缴台账。

### 4.7 数据中心（系统管理）

| 子功能 | 说明 |
|---|---|
| 数据库管理 | 备份、恢复（需 `pg_dump/pg_restore` 客户端，见 §8） |
| 数据导入 | 各类业务台账 Excel 导入（模板下载 → 导入 → 校验报告） |
| 数据导出 | Schema 报告、档案、月报、数据备份、系统日志等分类导出（默认输出至"文档"目录） |
| 数据字典 | 业务字典维护（分类、原因、状态等枚举） |
| 地区管理 | 省/市/区/乡镇/村五级行政区划维护 |
| 标准配置 | 收入标准、低保标准等政策参数维护（存于数据库，禁止硬编码） |

### 4.8 用户与权限管理

- **用户**：账户增删改、启用停用、重置密码（BCrypt 存储）。
- **角色**：角色维护 + 功能权限勾选（约 80 个权限码，覆盖查看/新增/编辑/删除/打印/审核分权）。
- **组织/经办机构**：机构树维护，支持 Excel 导入。
- **数据权限**：按机构/区域限定可见数据范围（`DataPermissionManager`）。

### 4.9 值班管理

值班表排班、值班成员维护、调班申请、节假日维护。

### 4.10 彩票助手（独立可选功能）

双色球/大乐透开奖数据与购彩辅助，**独立权限码 `LOTTERY_ACCESS`**，默认不对业务岗位开放，可通过角色权限单独授权。

- **开奖数据**：官方接口同步入库（福彩/体彩），支持增量同步与历史期号查询。
- **智能预测**：唯一算法为**基于 tensorflow LSTM 模型的彩票预测**（双色球/大乐透原生支持）。训练与预测数据均来自开奖数据下载链路落库的历史数据，需先在首页「同步开奖数据」，再「训练预测模型」（首次约 5-10 分钟），之后即可生成预测。
- **购彩记录**：每次生成预测自动入库，开奖后自动比对命中并按官方奖级结算（大乐透兼容 2026 年 9→7 奖级改版）。
- 另有随机机选与历史数据浏览。策略契合度不代表中奖概率，请理性购彩。

### 4.11 移动端（Android）

与桌面端共用同一套业务服务与数据库，提供手机版界面：登录、申请表单、工作流、复核、变更（死亡/户主/成员）、核对、档案查询、临时救助、高龄津贴、值班表、身份证扫描、打印任务等。

## 5 关键业务规则（验收要点）

1. **金额口径**：年值为权威基准，先汇总、最后一次性舍入到分；**禁止**从已舍入月值×12 反推年值；判定与落库同口径。
2. **状态机**：申请状态流转由统一状态机控制（Draft → Submitted → Approved → …），越权流转被拒绝并给出用户可读提示。
3. **渐退期**：停发前设过渡期（月数可配），期间按比例减发，到期自动提醒；保障金属审批结果，口径修正后不自动重算，需人工核定走变更流程。
4. **变更链**：户主死亡"停旧建新"，新旧档案通过接续链关联；跨大类重新认定自动补记 `CategoryAdd` 变更（幂等），保证月报新增明细与变更记录一致。
5. **月报周期**：B 线统计周期 = [上月(结算日+1) ~ 本月(结算日+1))，结算日可配（默认 15 日）；新增/退出/跨类转入分线统计，退出对象兜底纠治表按触发事件标记。
6. **审计**：关键业务操作（登录、审批、导入导出、权限变更、打印）写入业务/安全日志，必记点以 `Services\Core\ILoggerService.cs` 的 `LogBusiness`/`LogSecurity` 调用约定为准核验。

## 6 权限与安全

| 项 | 实现 |
|---|---|
| 身份认证 | 用户名 + 密码，BCrypt 加盐哈希存储，禁止明文/弱哈希 |
| 功能权限 | RBAC：用户 → 角色 → 权限码；操作前统一鉴权，未授权即拦截并提示 |
| 数据权限 | 按经办机构/区域过滤可见数据 |
| 数据库凭据 | 配置文件 `enc:` 密文（DPAPI 机器级），不入代码库、不入日志 |
| 日志脱敏 | 姓名、身份证号、电话、银行账号入日志前统一掩码 |
| 敏感数据 | 公民身份数据文件不入代码目录；PII 不落明文日志 |
| 传输 | 数据库连接走内网 PostgreSQL；在线更新通道见 §9 |

## 9 版本发布与在线更新

- **版本号规则**：`1.1.yyyyMMdd`（日期为发布日），三处同步（`app.ini` / 工程属性 / 安装包脚本）后一键发版。
- **发版产物**：Release 自包含发布 → Inno Setup 安装包 → 清单签名 → 上传更新服务器。
- **在线更新**：客户端按 `config\update.ini` 检查新版本，提示下载与安装（详见 `deploy\README.md`）；可配置最低兼容版本，低于该版本强制重装。
- **升级安全**：Schema 变更全部幂等（建表/补列/补索引/补外键），升级前建议先做数据库备份。

## 10 常见问题（FAQ）

**Q1：启动报"无法连接数据库"？**
依次检查：数据库服务是否运行、`config\database.ini` 的 Host/Port/库名/账号是否正确、防火墙是否放行 5432、数据库账号是否被锁。修改密码后重启应用即可（配置有进程内缓存）。

**Q2：把 `database.ini` 复制到新电脑报解密失败？**
`enc:` 密文为机器级 DPAPI，不可跨机。在新机器的配置向导中重新填写一次明文密码，应用会自动重新加密。

**Q3：启动页出现黄色"Schema 状态警告"？**
说明有表/索引/外键缺失（多为库权限不足或中途断开）。用具备 DDL 权限的账号重启一次应用即可自动补齐；仍失败请查 `err_*.log` 中的具体 SQL 错误。

**Q4：打印或导出提示找不到 Office/WPS？**
安装 Microsoft Office 或 WPS 任一版本并保持默认关联；服务器版 Windows 需安装支持 COM 的桌面组件。

**Q5：打印预览空白？**
预览基于 WebView2 + 内置 PDF 渲染，先确认 WebView2 Runtime 已安装，再重新生成文书。

**Q6：月报数字与预期不符？**
核对三点：① 月报周期结算日（`app.ini` 的 `BCycleSettleDay`）；② 是否存在跨大类接续链（应计入"跨类转入"而非普通新增）；③ 该档案是否为接续链新档（接续链新档不重复计入基础新增行）。

**Q7：忘记管理员密码？**
由具备"重置密码"权限的管理员在 用户与权限管理 中重置；初始管理员账号见交付清单。

**Q8：应用升级后数据会丢吗？**
不会。升级只替换程序文件，数据库与 `config\` 保留；升级前会自动校验 Schema 并幂等迁移。建议每次大版本升级前手动做一次数据库备份。

## 附录 A 验收冒烟路径（建议）

1. 安装 → 首次启动 → 配置向导连库 → Schema 状态检查通过（0 缺失）。
2. 登录（含"记住我"）→ 首页数据概览与提醒横幅正常。
3. 低收入人口救助帮扶 → 新建申请 → 五步表单填写 → 收入核算金额正确 → 分类判定 → 提交。
4. 工作流各标签页流转：草稿 → 编辑/删除 → 已建档 → 档案制作 → 已完结 → **查看档案（只读打开）**。
5. 动态管理：经济复核、成员变更、户主死亡（停旧建新 + 变更记录链完整）。
6. 渐退期：登记 → 到期提醒 → 减发核定 → 文书输出。
7. 高龄津贴：申请 → 审核 → 停发 → 月报。
8. 家庭经济状况核对：快速核对 → 报告月审 → 月报表。
9. 档案制作与打印：模板选纸 → 生成 → PDF 预览 → 打印（Office/WPS 各验一次）。
10. 数据中心：字典/地区/标准配置维护 → Excel 导入（含校验报告）→ 备份 → 恢复演练。
11. 权限：创建低权限账号验证菜单/按钮/数据范围隔离。
12. 报表：月报生成 → 导出 Excel → 数字与明细勾稽一致。
13. 日志：执行登录失败、审批、导入各一次，核对 `sec_/biz_/err_` 日志与脱敏效果。
14. 在线更新（如启用）：低版本 → 收到升级提示 → 升级后版本号正确、数据完好。
