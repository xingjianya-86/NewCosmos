# 临时救助 5 天逐笔时间曲线（2026-11-13 口径）

> 2026-11-13。临时救助（C 线）由**月度批次锚定**（公示固定 10~13 号、验收固定 13 号）改为**逐笔 5 天曲线**：
> 每笔档案跟着自己的申请日走，公示期不再集中、不再固定。权威实现：
> `Services\Utilities\BusinessTimelineService.cs` 的 `BuildTempReliefCurve` / `BuildTempReliefCurveCore`（曲线）
> 与 `CalculateCLine`（仅批次标签/补打窗口）；本文只记录口径与决策，不复述代码。

## 1. 唯一权威规则

以**申请日 D** 为锚，整条曲线全自动推导、5 天封顶（均为日历日，不规避休息日）：

| 节点 | 规则 | 用户输入 |
|---|---|---|
| 申请日 D | 不晚于今天（表单原有限制） | ✅ 表单选 |
| 公示起 S | **= D + 1** | ❌ 自动（只读） |
| 公示止 E | **= D + 3**（= S + 2，公示恒 **3 天**） | ❌ 自动（只读） |
| 验收日 | **= E + 1 = D + 4**（自动计算，不手填） | ❌ 自动 |
| 入户调查窗口 | **[D, S]**（申请日 ~ 公示起）；打印值 = clamp(今日最近工作日, 窗口) | ❌ 自动 |
| 月度批次 | 仅作**标签**：申请日 ≤ 当月 13 号归本月，超过顺延下月；补打中心窗口 (上月A, 本月A] 按申请日过滤 | — |

示例：

```
11-10 申请 → 公示 11-11 ~ 11-13 → 验收 11-14
11-03 申请 → 公示 11-04 ~ 11-06 → 验收 11-07
11-29 申请 → 公示 11-30 ~ 12-02 → 验收 12-03（批次标签仍为 12 月）
```

时序铁律恒成立：`申请日 ≤ 公示起 < 公示止 < 验收日`，公示恒 3 天，全周期 ≤ 5 天。

## 2. 与旧口径的差异

| 项 | 旧（2026-10-18 ~ 11-12） | 新（2026-11-13 起） |
|---|---|---|
| 公示起止 | 固定 A−3 ~ A−1（A = 每月 13 号顺延） | 逐笔 D+1 ~ D+3 |
| 验收日 | 固定 A（13 号，非工作日顺延） | 逐笔 D+4（= 公示止 + 1 日历日，不排工作日） |
| 入户调查窗口 | [A−5（顺延工作日）, 公示起] | [申请日 D, 公示起] |
| 月度批次 | 同时承载公示/验收/归属 | **仅作标签**与补打窗口过滤 |

## 3. 存量数据兼容（零迁移）

- **验收日**：旧规则公示止 = A−1，新规则验收 = 公示止 + 1 → **恒等于 A**，所有存量档案打印出的验收日与改前**逐条一致**。
- **公示起止**：库中值原样回显/打印，非草稿不重算；仅新建/草稿按新曲线预填。
- **入户调查打印值**：上界（公示起）不变；仅"窗口未开启"分支下界由 A−5 改为申请日，属可接受微差。
- **无数据库迁移**：入库仍只有公示起止两列，验收日/调查日均为计算值。
