# Android 数据录入版部署教程

> 2026-09-20 首版。仅覆盖数据录入功能（登录→列表→5 步表单→保存），打印由 PC 端完成。

## 一、环境准备（一次性）

### 1.1 安装 .NET 10 SDK

已有 Windows 开发机的跳过。确认版本：

```bash
dotnet --version   # 需要 10.0.x
```

### 1.2 安装 MAUI 工作负载

```bash
dotnet workload install maui-windows   # Windows 构建（已有）
dotnet workload install maui-android   # Android 构建
```

验证：

```bash
dotnet workload list
# 应显示 maui-windows 和 maui-android 均已安装
```

### 1.3 安装 JDK 17

Android SDK 需要 JDK 17。下载 OpenJDK 17：

```powershell
# 方式一：下载 zip 解压（推荐）
curl.exe -L -o openjdk17.zip "https://download.java.net/java/GA/jdk17.0.2/dfd4a8d0985749f896bed50d7138ee7f/8/GPL/openjdk-17.0.2_windows-x64_bin.zip"
Expand-Archive openjdk17.zip -DestinationPath C:\AndroidJdk
# 解压后路径：C:\AndroidJdk\jdk-17.0.2

# 方式二：安装 Adoptium/Temurin JDK 17
# https://adoptium.net/temurin/releases/?version=17
```

设置环境变量（永久）：

```powershell
# 设置 JAVA_HOME（系统环境变量）
[System.Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\AndroidJdk\jdk-17.0.2", "Machine")
# 加入 PATH
$currentPath = [System.Environment]::GetEnvironmentVariable("Path", "Machine")
[System.Environment]::SetEnvironmentVariable("Path", "$currentPath;C:\AndroidJdk\jdk-17.0.2\bin", "Machine")
```

验证：

```bash
java -version
# openjdk version "17.0.2"
```

### 1.4 安装 Android SDK

```powershell
# 下载 Android 命令行工具
$sdkUrl = "https://dl.google.com/android/repository/commandlinetools-win-11076708_latest.zip"
curl.exe -L -o cmdtools.zip $sdkUrl
Expand-Archive cmdtools.zip -DestinationPath cmdtools

# 安装到标准位置
$androidSdk = "$env:LOCALAPPDATA\Android\Sdk"
New-Item -ItemType Directory -Path "$androidSdk\cmdline-tools" -Force
Move-Item cmdtools\cmdline-tools "$androidSdk\cmdline-tools\latest"

# 设置 ANDROID_HOME
[System.Environment]::SetEnvironmentVariable("ANDROID_HOME", $androidSdk, "Machine")

# 接受许可证并安装组件
$env:JAVA_HOME = "C:\AndroidJdk\jdk-17.0.2"
$env:PATH = "$env:JAVA_HOME\bin;$androidSdk\cmdline-tools\latest\bin;$env:PATH"

# 手动创建许可证文件（避免交互）
$licDir = "$androidSdk\licenses"
New-Item -ItemType Directory -Path $licDir -Force
Set-Content "$licDir\android-sdk-license" "`n24333f8a63b6825ea9c5514f83c2829b004d1fee`n84831b9409646a918e30573bab4c9c91346d8abd`nd56f5187479451eabf01fb78af6dfcb131a6481e`n"
Set-Content "$licDir\android-sdk-arm-dbt-license" "`n859f317696f67ef3d7f30a50a5560e7834b43903`n"

# 安装 SDK 组件
sdkmanager.bat "platforms;android-36" "build-tools;36.0.0" "platform-tools"
```

验证：

```bash
sdkmanager.bat --list_installed | findstr "android-36"
# platforms;android-36
```

## 二、编译 Android APK

### 2.1 常规编译（Debug）

```bash
# 确保环境变量正确
set JAVA_HOME=C:\AndroidJdk\jdk-17.0.2
set ANDROID_HOME=%LOCALAPPDATA%\Android\Sdk

# 编译 Android 版本
dotnet build NewCosmos.csproj -f net10.0-android36.0 -p:JavaSdkDirectory="C:\AndroidJdk\jdk-17.0.2"
```

### 2.2 发布 APK（Release）

```bash
dotnet publish NewCosmos.csproj -f net10.0-android36.0 -c Release -r android-arm64 -p:JavaSdkDirectory="C:\AndroidJdk\jdk-17.0.2"
```

产物位置：`bin\Release\net10.0-android36.0\android-arm64\publish\`

### 2.3 同时编译两个平台

```bash
# 编译 Windows 版
dotnet build NewCosmos.csproj -f net10.0-windows10.0.19041.0

# 编译 Android 版
dotnet build NewCosmos.csproj -f net10.0-android36.0 -p:JavaSdkDirectory="C:\AndroidJdk\jdk-17.0.2"
```

> **注意**：多目标框架编译（不指定 `-f`）会同时编译两个平台，耗时较长且需要两个平台的工具链。建议日常开发用 `-f` 指定单平台。

## 三、部署到 Android 设备

### 3.1 开启开发者模式

1. Android 设备 → 设置 → 关于手机 → 连续点击"版本号" 7 次
2. 返回设置 → 开发者选项 → 开启"USB 调试"
3. 用 USB 线连接电脑，设备弹窗点"允许"

### 3.2 安装 APK

```bash
# 方式一：通过 adb 直接安装
adb install path\to\NewCosmos.apk

# 方式二：通过 dotnet run（需连接设备）
dotnet run --project NewCosmos.csproj -f net10.0-android36.0 -p:JavaSdkDirectory="C:\AndroidJdk\jdk-17.0.2"
```

### 3.3 无线调试（Android 11+）

```bash
# 先用 USB 连接一次
adb tcpip 5555
adb connect <设备IP>:5555
# 拔掉 USB 线，后续通过网络调试
```

## 四、网络配置（ZeroTier）

Android 版通过 ZeroTier 直连 PostgreSQL 数据库，无需额外 API 层。

### 4.1 安装 ZeroTier

1. Google Play 搜索 **ZeroTier One** 并安装
2. 打开 App → 输入网络 ID（与 PC 端相同的 ZeroTier 网络）
3. 等待管理员在 ZeroTier Central/Web 控制台批准设备
4. 获得分配的虚拟 IP（形如 `10.x.x.x`）后即连接成功

### 4.2 配置数据库连接

首次启动 App → 登录页底部"配置"→ 填写：

| 字段 | 值 |
|---|---|
| 服务器地址 | `10.x.x.x`（ZeroTier 内网 IP，按实际分配填写） |
| 端口 | `5432` |
| 数据库名 | `cosmos_next` |
| 用户名 | `new_cosmos` |
| 密码 | 数据库密码 |

### 4.3 网络故障排查

| 现象 | 检查 |
|---|---|
| 连不上数据库 | ZeroTier App 是否在线（状态显示"ON"） |
| ZeroTier 显示 ACCESS_DENIED | 需要在 ZeroTier Central 授权设备 |
| 连接超时 | PostgreSQL 是否允许来自 ZeroTier IP 的连接 |
| 断连后重连 | ZeroTier App 在部分国产 ROM 上可能被杀后台，需关闭电池优化 |

## 七、开发调试

### 7.1 Hot Reload

```bash
dotnet build NewCosmos.csproj -f net10.0-android36.0 -t:Run -p:JavaSdkDirectory="C:\AndroidJdk\jdk-17.0.2"
```

修改 XAML 后自动热重载（需设备连接）。

### 7.2 日志查看

```bash
# 查看 App 日志
adb logcat -s "NewCosmos"

# 查看崩溃日志
adb logcat --pid=$(adb shell pidof com.newcosmos.app)
```

### 7.3 常见编译错误

| 错误 | 解决 |
|---|---|
| `NETSDK1140: 35.0 不是有效的 TargetPlatformVersion` | csproj 中 TFM 应为 `net10.0-android36.0`（不是 35.0） |
| `XA5300: 找不到 Android SDK 目录` | 设置 `ANDROID_HOME` 环境变量 |
| `XA5300: 找不到 Java SDK 目录` | 设置 `JAVA_HOME` 或传 `-p:JavaSdkDirectory=...` |
| `APT2260: network_security_config not found` | XML 资源需在 `Platforms/Android/Resources/xml/` 目录 |
| `XAPRAS7009: PE image does not have metadata` | 排除原生 DLL（Python/PostgreSQL/ZeroTier 已在 csproj 中条件化） |
