# 登录页「技术档案」风格改版（2026-10-28）

> 目标：登录页与启动动画（`Resources\Splash`，dsh-startup-screen 二次开发版）使用同一套视觉语言，
> 让「启动动画 → 揭幕 → 登录」是一条连续的观感，而不是"动画很帅、登录页很丑"。

## 1. 视觉规范（页面级，不影响全局样式）

| 用途 | 值 | 定义位置 |
|---|---|---|
| 底板渐变 | `#E5E3DF → #ECEAE6`（135°） | `LoginPage.xaml` 的 `Plate`；`Resources\Splash\app.css` 的 body 底板（**两处必须一致**） |
| 档案条水印 | `#D9D6D0`，三条竖带（45% / 32% / 20%） | `LoginPage.xaml` 底板 Grid；`app.css` 同款渐变 |
| 机框 / hairline | `#290A0A0A`（≈10% 黑） | `Hair` / `HairSoft` |
| 文字 | ink `#0A0A0A` / soft `#3A3936` / muted `#7A7873` | `Ink` / `InkSoft` / `Muted` |
| 强调 | 系统 `Primary` `#1a73e8`（聚焦描边、阶段柱、按钮、页脚进度段） | 全局 `Colors.xaml` |
| 字体 | 标题 Bahnschrift（Android 回退 `sans-serif-condensed`）；小字 Cascadia Mono（Android `monospace`）；中文微软雅黑 | `OnPlatform` 内联 |

## 2. 版式

**桌面/平板**（`OnIdiom Desktop/Tablet`）
- 右上：`REV {app.ini 版本} · DESKTOP {实时时钟}` + `ACCESS TERMINAL`
- 左列（整组垂直居中）：品牌三行（NEWCOSMOS / SOCIAL ASSISTANCE MANAGEMENT / 帝皇权杖 δ-me13）→ 吉祥物 + 环形准星（外环自转）→ 「操作员登录 / OPERATOR SIGN-IN」→ 分隔线 + 6 格阶段柱（首格点亮）
- 右列：档案「访问授权」面板（细线直角、`01 / 01`）→ `OPERATOR` / `PASSKEY` 字段（聚焦时左侧强调条 + 边框变主题蓝）→ 记住账号/密码 → 错误提示（等宽红字）→ 双语按钮「授权访问 / GRANT ACCESS」
- 页脚：© 行 + 主题色进度段 + `· SESSION : STANDBY`（底部 padding 58，避开系统任务栏）

**手机**（`OnIdiom Phone`）
单列 ScrollView：品牌块 → 紧凑时钟 → 吉祥物+准星（150px）→ 「操作员登录」→ 同款面板 → 页脚；字段标签改为上下排（窄屏放不下左侧定宽标签）。

## 3. 动效（原生 MAUI，低开销）

| 动效 | 实现 | 位置 |
|---|---|---|
| 品牌块左→右擦出 | `TranslateToAsync` + `FadeToAsync` | `PlayEntrance` |
| 状态区 / 面板淡入上浮 | 同上，错开 90/160ms | `PlayEntrance` |
| 准星匀速自转 | `Animation` 0→360，`repeat: true`，18s/圈 | `StartAmbientAnimation` |
| 按钮呼吸 | Opacity 1↔0.93（幅度必须小，否则显脏） | 同上 |
| 实时时钟 | `DispatcherTimer` 1s，仅更新两个 Label 文本 | `StartClock` |

离开页面：`AbortAnimation` + 停表（`OnDisappearing`）。

## 4. 与启动动画的衔接

- 启动动画揭幕淡出后露出的是 `Resources\Splash\app.css` 的 body 底色；
  它必须与本页 `Plate` 渐变逐值一致，否则切页会"跳色"。
- `SplashAssetsService` 已不再复制/使用 `img/bg.webp`（旧版用登录背景图做揭幕底），
  改为纯色板后少一次运行时文件拷贝。

## 5. 维护要点

- **WinUI Entry 双层框**：WinUI `TextBox` 自带边框与聚焦描边，叠在档案面板外框上会变成"双层框"。
  `LoginPage.xaml.cs` 的 `StripWindowsEntryChrome` 除了 `BorderThickness=0`，
  还必须覆盖主题资源键 `TextControlBorderBrush*` / `TextControlBorderThemeThickness*`，
  否则聚焦时会被可视状态重新画上蓝框。
- **改文案**：只改 `LoginPage.xaml` 中的两处（桌面/手机各一）「操作员登录 / OPERATOR SIGN-IN」与面板标题；
  不要动绑定名（`Username/Password/RememberMe/RememberPassword/LoginCommand/ErrorMessage/HasError/IsNotBusy`）。
- **改底板色**：`LoginPage.xaml` 的 `Plate` 与 `Resources\Splash\app.css` 必须同步修改。

## 6. 冒烟

- Windows：默认态 / 聚焦态（强调条+蓝边）/ 错误提示 / 记住账号密码回填 / 登录成功；
- 启动动画揭幕 → 登录页无跳色；
- Android：`dotnet build -f net10.0-android36.0` 零错误 + 真机查看手机版式（键盘遮挡、状态栏深色图标）。
