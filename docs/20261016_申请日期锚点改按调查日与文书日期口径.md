# 申请日期锚点改按调查日 与 文书日期口径（承诺时间/入户时间）改造

> 2026-10-16。一次性解决三件事：① {诚信承诺时间} 取值错误（隋淑凤 8-24 早于公示 15 天）；
> ② 入户调查时间倒挂档落进公示期（违反"入户不得在公示期/会议日之后"铁律）；
> ③ 申请日期改由表单所选**调查日期**计算，UI 同步增加**时间排斥原则**。
> 权威代码：`Helpers\ArchiveAnchorHelper.cs`（双锚点单点）→ 本文只记录口径与决策，不复述代码。

## 1. 锚点设计（双锚点，职责分离）

| 锚点 | 取值 | 用途 |
|---|---|---|
| **受理锚点** `ResolveApplicationDate` | 申请编号内嵌日期(SA+yyyyMMdd) → 创建 → 首次审批 → 补全完成 → 更新 → 今天（**原链不变**） | ① Step4 时间排斥校验的窗口参照 ② 业务锚点周期差护栏的比较基准 ③ 状态时序告警 |
| **业务锚点** `ResolveBusinessAnchorDate`（新） | **调查日期**，生效条件：调查日归属周期与受理周期**周期差 ∈ {0, +1}**；否则回退受理锚点 | 文书 B 线周期计算（公示/会议/审核确认/生效/卷号）、APPLICATION_DATE 占位符、入户口径下限、PROMISE_DATE 兜底 |

- 周期差 0：同批次，仅"申请日期"显示值改取调查日；周期差 +1：业务顺延下一周期（时间往下走，典型：建档 8-24、入户 9-21 的隋淑凤）；
- 其余（滞后 ≥2 或超前周期，含调查日为 2016/2019 等历史错位数据）→ 回退受理锚点，**防止文书打出远年公示/生效/卷号**；
- 计算入口：档案两处字段构建器 `ArchiveProductionViewModel.ResolveBusinessAnchor`、`TemplateFieldBuilder.BuildFieldsAsync`、卷号/目录 `ArchiveOutputViewModel.ResolveApplicationDateForTimelineAsync`——均调用单点，禁止各自重算。
- 窗口内调查日数学上必与受理日同周期（调查 ≤ 会议日 ⟹ 不滚周期），故**新数据零批次漂移**。

## 2. UI 时间排斥原则（表单 Step4 调查日期，硬校验）

1. **不得早于申请日期**（受理锚点）——防"调查早于建档"倒挂（存量豁免：已存档未改动放行）；
2. **不得晚于今天**（本次新增）——建档晚于当月会议日时上限会顺延成未来日，仅靠上限拦不住未来日期；
3. **不得晚于公示开始前一个工作日（=会议日）**——铁律前移：新数据不可能再产生窗口外调查日；
   打印侧周期差护栏只服务存量/豁免数据。
   豁免①补全锁定档、豁免②存量原值未改动，均保持原状。

## 3. {诚信承诺时间} 口径 → 新字段键 PROMISE_DATE

- `PROMISE_DATE` = **首次审批日**（未审批兜底 = 业务申请日期）；**已批档案钳下限公示开始日**
  （用户拍板**保留下限**：承诺落款不得早于公示）。
- 模板换绑（`nc_biz_templates.config_json`，{诚信承诺时间} fieldKey → PROMISE_DATE）：
  **174 通用_申请人承诺书、178 通用_经办人承诺书**（两者 directoryDateField 同步 → PROMISE_DATE）、
  **196 档案_村级土地说明、200 档案_赡养费承诺书**（directoryDateField 维持 SURVEY_DATE）。
- 填值线 3 条：档案主构建、缓存构建、**临时救助 TempReliefPrintDataBuilder**（174/178 挂临时救助分类；
  C 线**不套** B 线规则，维持现状值 = 调查日/申请日——用户决策第 4 条）。
- 取值推导记录：申请日（隋 8-24 ✗）/ 原始入户日（刘 10-08 早于其公示 ✗）/ 入户钳制（隋 9-7 ✗）
  ——仅**首次审批日**同时满足刘（10-12 ∈ 公示期）与隋（9-21 ≥ 公示开始）两案例且结构上不早于公示。
- 模板 1/170/241 的 {申请时间/申请日期} 仍绑 APPLICATION_DATE，语义随业务锚点（=调查日），未换键。

## 4. 入户调查日期/时间口径（`ResolveSurveyDate` 两处同步）

- 上限铁律：入户 ≤ 会议日（公示前一工作日），**永不失效**；
- **倒挂窗口（申请日 > 会议日）时上限优先**，放弃"不早于申请日"下限：
  如申请 10-12、会议 10-08、调查 10-08 → 打印 10-08（旧实现顶到 10-12，恰落公示期）；
- 正常窗口维持 [申请日, 会议日] 双钳（建档自愈保留）；
- `SURVEY_TIME`（254 定期复核审批表、255 增员减员调整表）改取与 SURVEY_DATE **同源同串**，
  去掉 `DateTime.Now / HH:mm`（库里只有日期没有时刻）。

## 5. 迁移审计（全库 36 条，2026-10-16 实测）

- 调查日 = 编号日 22 条 → 锚点无变化；
- 周期差 0 生效（仅显示值变化）：刘明珍（10-12→10-08）、id96（10-15→9-30）、id47/45/44（→8-07）；
- 周期差 +1 顺延：**隋淑凤**（8-24 → 锚 9-21，业务顺延 10 月周期）；
- 回退受理锚点（历史错位，含调查日 2016/2017/2019/2021/2023 共 9 条 + id52 早于周期起）→ 与今日打印完全一致；
- `submit_at`（第一次正式提交）全库 0 填充：状态机 Draft→Submitted 写入点存在但主表单提交恒落 Draft，
  "提交日锚定"暂无数据可用——若日后启用，作为独立字段另立项，不混入本口径。
