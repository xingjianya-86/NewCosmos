这一枚徽标解决什么

  • 用户一眼知道自己在哪一端登录，避免「网页还是应用」混淆。
  • 管理员在「在线会话」里按 T1–T7 一眼定位是哪台客户端。
  • 徽标由 device_kind 决定，不信任客户端自报名称。
  • 印色只作强调，底色、文字、发丝线、圆角仍走原纸墨令牌。

身份识别（新增）

  • 两端 SessionConstants 增加 6 个 kind 与端族映射。

互踢规则（不变）

  • 桌面族 desktop / web / shell 共用 max_desktop=1。
  • 移动族 android / mobile-web / capacitor 共用 max_mobile=1。
  • 新登录顶掉旧端；桌面 + 移动仍可并存。
  • 同 device_id 重复登录一律顶号，不留垃圾行。

被顶号提示（统一）

  • 桌面端：SnackBar「账号已在其他设备登录」+ 30 秒保存宽限。
  • 网页端：把服务端 SESSION_REPLACED 消息透传到 Toast，不再泛化成「登录状态已失效」。
  • 两端文案同源 SessionConstants.GetEndedMessage。
